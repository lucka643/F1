# F1 Highway Drive — Preview

This is the **playable preview build** requested for GitHub Pages.

## Assets

- **Oracle Red Bull F1 Car RB19 2023** by Redgrund — CC BY 4.0. The final build is being prepared from the supplied GLB.
- **NFS Undercover DS – Highway Battle** by amogusstrikesback2 — CC BY 4.0. The preview roadway centre line was extracted from the supplied GLB so the preview follows the uploaded highway layout.

## Preview scope

The preview intentionally uses a lightweight procedural F1 body while the full supplied RB19 asset pipeline is completed. It includes the extracted highway layout, steering, wheel spin, acceleration/braking/reverse, barriers, basic grip/downforce behaviour, camera presets, weather/time controls, touch controls, respawn and desktop controls.

The final build will replace preview geometry/material shortcuts with the prepared supplied assets and expanded physics/graphics systems.
